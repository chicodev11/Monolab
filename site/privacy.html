What Monolab sends

Monolab runs your servers on your own machines. Your worlds, files, console output and commands stay there. This page lists everything the app sends to mnlab.cc, what is kept, and how to turn it off.

Anonymous usage counts

The app keeps a connection to mnlab.cc so it hears right away when a new Monolab add-on or PumpkinMC build is out. On that connection it sends:

Install ID
A random number made on your PC the first time counts are on. It isn't tied to your name, your Discord account or your hardware. It lets us count each install once a day.
Versions
The app version, the add-on version and the PumpkinMC fork build in the app.
Operating system
The system and processor type, such as windows-x86_64.

From this we see how many installs were used today, this week and this month, and which versions and systems are in use, so we know which ones still need fixes. Each day an install was seen is kept for 400 days and then deleted.

What is never sent

  • Server names, addresses, ports, worlds, files, plugins, console output or commands.
  • Your account details on this PC, SSH logins, game panel keys or web panel accounts.
  • Your IP address is not stored. The server holds it in memory only to limit how often one address can connect, and forgets it after that.

Turning it off

Open Settings in the app and switch off Send anonymous usage counts. The app tells you about this once, the first time it starts.

With the switch off, no install ID is sent. The app still connects to mnlab.cc to hear about add-on and fork updates and sends the versions and system it needs for that, but the server can't tell your install apart from any other, so you aren't counted.

Monolink accounts

If you sign in to Monolink with Discord, the account server stores:

  • Your Discord user ID, your Monolab handle and your avatar.
  • The devices you signed in on, with their names and when each was last seen.
  • The teams you are in and your role in each.

Teammates' apps connect straight to each other, encrypted. The account server never receives files, console output or commands. If you never sign in, none of this exists.

Crash reports

Crash reports are only sent when you choose to send one. Nothing is sent on its own when the app crashes.

Our server and this website

  • The web server at mnlab.cc keeps access logs for 14 days. Invite codes and sign-in codes are left out of them.
  • This website sets no cookies and has no analytics. The download buttons ask GitHub which release is the newest, so your browser talks to api.github.com when a page opens.
  • App updates, add-ons and PumpkinMC builds are downloaded from GitHub releases, and GitHub's own privacy terms apply to those downloads.

Contact

Questions about this page, or a request to remove your Monolink account: open an issue at github.com/chicodev11/Monolab/issues.
